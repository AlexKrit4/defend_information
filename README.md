# Защита информации — лабораторные работы 1–6

**Вариант 11.** Реализация на Python 3 (только стандартная библиотека).

| № | Тема | Параметры варианта |
|---|------|--------------------|
| 1 | Шифр перестановки | группа `[1 2 3 4 5 6] → [2 6 3 5 1 4]`, текст в ASCII-коде |
| 2 | Гаммирование | линейный конгруэнтный генератор ПСЧ, b = 7 |
| 3 | Сеть Фейстеля | 28 раундов, образующая функция — умножение mod 2³² |
| 4 | RSA | ключи генерируются, криптограмма → `cipher.txt` |
| 5 | ЭЦП ГОСТ Р34.10-94 | хэш — произведение кодов символов mod 2¹⁶ |
| 6 | Парольная защита | метод выборки символов |

## Запуск

```bash
python lab1/lab1.py
python lab2/lab2.py
# и т.д.
```

Работает в GitHub Codespaces и на любой машине с Python 3 —
зависимостей нет. В `lab6` под Windows ввод маскируется `*`,
под Linux — обычный посимвольный ввод с Enter.

Полный отчёт со всеми разделами, листингами, результатами работы и
ответами на контрольные вопросы — в `ОТЧЁТ.md` / `ОТЧЁТ.docx`.
