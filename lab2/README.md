# RSA Шифр - Лабораторная работа №2

## Описание

Реализация асимметричного шифра RSA (Rivest–Shamir–Adleman) на языке Python.

RSA — системасимметричного шифрования, которая использует две ключа:
- **Открытый ключ (public key)** — известен всем, используется для шифрования
- **Закрытый ключ (private key)** — известен только получателю, используется для расшифрования

## Как работает RSA

### 1. Генерация ключей

**Шаг 1:** Выбрать два больших простых числа `p` и `q`
```python
p = 7
q = 13
```

**Шаг 2:** Вычислить `n = p × q`
```python
n = 7 × 13 = 91
```

**Шаг 3:** Вычислить функцию Эйлера `φ(n) = (p-1) × (q-1)`
```python
φ(n) = (7-1) × (13-1) = 6 × 12 = 72
```

**Шаг 4:** Выбрать открытую экспоненту `e` такую, что `gcd(e, φ(n)) = 1`
```python
e = 5  (так как gcd(5, 72) = 1)
```

**Шаг 5:** Вычислить закрытую экспоненту `d` из соотношения `(d × e) mod φ(n) = 1`
```python
Используем формулу: d = (1 + k × φ(n)) / e

При k=1: d = (1 + 1×72) / 5 = 73/5 — не целое
При k=2: d = (1 + 2×72) / 5 = 145/5 = 29 ✓

Проверка: (29 × 5) mod 72 = 145 mod 72 = 1 ✓
```

**Результат:**
- Открытый ключ: **(e, n) = (5, 91)**
- Закрытый ключ: **(d, n) = (29, 91)**

### 2. Шифрование

Формула: **C = T^e mod n**

Где:
- `T` — числовой код исходного символа
- `C` — числовой код зашифрованного символа

Пример для сообщения "КАФСИ":
```
К (код 12) -> 12^5 mod 91 = 248832 mod 91 = 38
А (код 1)  -> 1^5 mod 91 = 1
Ф (код 22) -> 22^5 mod 91 = 5153632 mod 91 = 29
С (код 19) -> 19^5 mod 91 = 2476099 mod 91 = 80
И (код 10) -> 10^5 mod 91 = 100000 mod 91 = 82

Шифрограмма: [38, 1, 29, 80, 82]
```

### 3. Расшифрование

Формула: **T = C^d mod n**

Пример расшифрования:
```
38 -> 38^29 mod 91 = 12
1  -> 1^29 mod 91 = 1
29 -> 29^29 mod 91 = 22
80 -> 80^29 mod 91 = 19
82 -> 82^29 mod 91 = 10

Восстановленное: К А Ф С И
```

### 3. Использование в коде

```python
from rsa import RSA

# Создаем RSA с параметрами из лабораторной работы
rsa = RSA(p=7, q=13, e=5)

# Шифруем сообщение
message = "КАФСИ"
encrypted = rsa.encrypt(message)
print(f"Шифрограмма: {encrypted}")  # [38, 1, 29, 80, 82]

# Расшифровываем
decrypted = rsa.decrypt(encrypted)
print(f"Восстановлено: {decrypted}")  # КАФСИ

# Получаем ключи
public_key = rsa.get_public_key()   # (5, 91)
private_key = rsa.get_private_key() # (29, 91)
```

## Методы класса RSA

### Конструктор

```python
RSA(p=None, q=None, e=None)
```

Параметры:
- `p` — первое простое число
- `q` — второе простое число
- `e` — открытая экспонента (опционально, выбирается автоматически)

### Основные методы

```python
# Шифрование сообщения
encrypted = rsa.encrypt(message: str) -> list

# Расшифрование сообщения
message = rsa.decrypt(encrypted: list) -> str

# Кодирование текста в коды
codes = rsa.encode_text(text: str) -> list

# Декодирование кодов в текст
text = rsa.decode_text(codes: list) -> str

# Получить открытый ключ
pub_key = rsa.get_public_key() -> tuple (e, n)

# Получить закрытый ключ
priv_key = rsa.get_private_key() -> tuple (d, n)
```

## Важные свойства RSA

1. **Математическая связь ключей:**
   - (d × e) mod φ(n) = 1
   - Зашифрованное одним ключом можно расшифровать только другим

2. **Стойкость:**
   - Основана на сложности разложения больших чисел на множители
   - Чем больше p и q, тем выше стойкость

3. **Ограничения в этой реализации:**
   - Малые значения p и q (только для образовательных целей)
   - Может шифровать только коды символов (до 256)
   - Реальный RSA использует числа размером 1024-4096 бита

## Безопасность

В реальных приложениях RSA:
- Использует числа, содержащие 1024 или более бит
- Не использует напрямую для больших объемов данных (используется гибридное шифрование)
- Применяется с дополнительными схемами заполнения (OAEP)

В этой лабораторной работе используются малые числа для образовательных целей.
