## 📋 Структура программы

```
RSA (класс)
├── __init__(p, q, e) — создает ключи
├── encrypt(message) — шифрует текст
├── decrypt(encrypted) — расшифровывает
├── encode_text(text) — текст → коды
├── decode_text(codes) — коды → текст
├── get_public_key() — возвращает (e, n)
└── get_private_key() — возвращает (d, n)
```

## 🧮 Пример использования

```python
from rsa import RSA

# Создаем RSA с параметрами p=7, q=13, e=5
rsa = RSA(p=7, q=13, e=5)

# Шифруем сообщение
message = "КАФСИ"
encrypted = rsa.encrypt(message)
print(encrypted)  # [38, 1, 29, 80, 82]

# Расшифровываем
decrypted = rsa.decrypt(encrypted)
print(decrypted)  # КАФСИ

# Проверяем
print(message == decrypted)  # True
```

## 🔑 Пример из лабораторной

```
p = 7, q = 13, e = 5
↓
n = 91, φ(n) = 72, d = 29
↓
Открытый ключ:  (5, 91)
Закрытый ключ:  (29, 91)
↓
Сообщение КАФСИ:
  К (12) → 12^5 mod 91 = 38
  А (1)  → 1^5 mod 91 = 1
  Ф (22) → 22^5 mod 91 = 29
  С (19) → 19^5 mod 91 = 80
  И (10) → 10^5 mod 91 = 82
↓
Шифрограмма: [38, 1, 29, 80, 82]
↓
Расшифрование:
  38 → 38^29 mod 91 = 12 → К
  1  → 1^29 mod 91 = 1 → А
  29 → 29^29 mod 91 = 22 → Ф
  80 → 80^29 mod 91 = 19 → С
  82 → 82^29 mod 91 = 10 → И
↓
Восстановленное: КАФСИ ✅
```

## 💡 Ключевые формулы (шпаргалка)

### 1. Генерация ключей
```
n = p × q
φ(n) = (p-1) × (q-1)
gcd(e, φ(n)) = 1
(d × e) mod φ(n) = 1
```

### 2. Шифрование
```
C = T^e mod n
```

### 3. Расшифрование
```
T = C^d mod n
```

### 4. Вычисление d
```
d = (1 + k×φ(n)) / e
где k подбирается до получения целого числа
```
