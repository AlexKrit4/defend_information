### 1️⃣ Генерация ключей
```
p = 7, q = 13, e = 5
↓
n = 91, φ(n) = 72
↓

Открытый ключ:  (5, 91)
Закрытый ключ:  (29, 91)
```

### 2️⃣ Пример из задания - КАФСИ
| Символ | Код | Шифрование | Результат | Расшифрование | Восстановлено |
|--------|-----|-----------|-----------|---------------|---------------|
| К      | 12  | 12^5 mod 91 | 38     | 38^29 mod 91  | К ✓          |
| А      | 1   | 1^5 mod 91  | 1      | 1^29 mod 91   | А ✓          |
| Ф      | 22  | 22^5 mod 91 | 29     | 29^29 mod 91  | Ф ✓          |
| С      | 19  | 19^5 mod 91 | 80     | 80^29 mod 91  | С ✓          |
| И      | 10  | 10^5 mod 91 | 82     | 82^29 mod 91  | И ✓          |

**Шифрограмма:** 38, 1, 29, 80, 82

### 3️⃣ Ключевые формулы

**Генерация n:**
```
n = p × q = 7 × 13 = 91
```

**Функция Эйлера:**
```
φ(n) = (p-1) × (q-1) = 6 × 12 = 72
```

**Ограничение на e:**
```
gcd(e, φ(n)) = 1
gcd(5, 72) = 1 ✓
```

**Вычисление d:**
```
(d × e) mod φ(n) = 1
(29 × 5) mod 72 = 145 mod 72 = 1 ✓
```

**Шифрование:**
```
C = T^e mod n = 12^5 mod 91 = 38
```

**Расшифрование:**
```
T = C^d mod n = 38^29 mod 91 = 12
```

## 💬 Что рассказать преподавателю

**"RSA работает, потому что:"**

1. **Математическая основа** — основано на теореме Эйлера: a^φ(n) ≡ 1 (mod n)

2. **Асимметрия** — открытый и закрытый ключи математически связаны, но независимы друг от друга

3. **Сложность взлома** — стойкость основана на сложности факторизации (разложения n на p и q)

4. **Корректная реализация** — все формулы проверены на примере из лабораторной работы
