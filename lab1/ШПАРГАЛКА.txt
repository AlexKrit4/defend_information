# Краткая справка для презентации

## Быстрый старт для демонстрации преподавателю

### 1️⃣ Задание 1: Представление текста
```bash
ls -lh 1.txt 1.docx
```
**Результат:**
- `1.txt` = 16 байт (просто текст)  
- `1.docx` = 13514 байт (форматирование + структура XML)

**Что рассказать:** В одном файле 816 байт, в другом 844 раза больше! Один и тот же текст — разное представление в компьютере.

---

### 2️⃣ Задание 2.1: Размер файла
```bash
echo "1.txt" | ./task2_1
```
**Результат:** File size: 16 bytes

**Что это:** Программа считывает файл построчно и подсчитывает байты.

---

### 3️⃣ Задание 2.2: Частота байтов (статистика текста)
```bash
echo "1.txt" | ./task2_2
```
**Результат:**
```
Byte | Count | Frequency | Character
-----+-------+-----------+-----------
105  |   5   |  31.25%   | i
32   |   2   |  12.5%    | (space)
44   |   2   |  12.5%    | ,
...
```

**Что это означает:**
- Буква 'i' встречается в 31% всех байтов
- Это статистическая особенность текста
- На этом основан криптоанализ (взлом простых шифров)

---

### 4️⃣ Задание 3: Шифр вертикальной перестановки

**Шифрование:**
```bash
echo -e "1\n1.txt" | ./task3
# Результат: encrypted.bin (20 байт вместо 16)
```

**Расшифрование:**
```bash
echo -e "2\nencrypted.bin" | ./task3
# Результат: decrypted.bin (оригинальный текст + zzz)
```

**Как это работает:**
1. Записываем текст в таблицу (5 столбцов)
2. Переставляем столбцы по ключу из key.txt
3. Читаем построчно — получается криптотекст
4. Обратный процесс дешифрует сообщение

**Ключ:** 3 1 4 2 5 (читать в key.txt)

## Файловая структура
```
lab1/
├── 1.docx          ← Word документ (задание 1)
├── 1.txt           ← Текстовый файл (данные для программ)
├── task2_1.cpp     ← Считывает размер файла
├── task2_2.cpp     ← Анализирует частоту байтов
├── task3.cpp       ← Шифр вертикальной перестановки
├── key.txt         ← Ключ для шифра (3 1 4 2 5)
├── README.md       ← Подробное объяснение
└── (исполняемые файлы и выходные데이터)
```

## Что показать преподавателю в таком порядке

1. **Размеры файлов** — `ls -lh 1.*` (наглядно: 16 байт vs 13 KB)
2. **Частота букв** — запустить task2_2 (показать статистику)
3. **Шифрование** — запустить task3 в режиме 1
4. **Расшифрование** — запустить task3 в режиме 2
5. **Проверка** — `./task2_1` для расшифрованного файла

## Основные идеи (главное, что взять на главное)

✅ **Представление данных** — один и тот же смысл, разные размеры  
✅ **Статистика** — текст не случаен, буквы имеют характерные частоты  
✅ **Криптография** — как шифровать данные перестановкой  
✅ **Расшифровка** — как восстановить сообщение, зная ключ
