# Лабораторная работа № 1. Шифрование методом перестановки

## Цель работы
Изучить основы построения классических криптоалгоритмов шифрования
методом перестановки, научиться шифровать и дешифровать данные.

## Задание (вариант 11)
* Метод шифрования — **перестановка**;
* таблица 1.3 «Группы перестановок», задание №4:

      / 1 2 3 4 5 6 \
      \ 2 6 3 5 1 4 /

* представление исходного текста — **ASCII-код**.

## Описание метода
При шифровании перестановкой символы (элементы) открытого текста не
заменяются другими, а переставляются внутри блока по заданной группе
перестановок. Криптографическим ключом является сама группа перестановок
и длина блока.

Так как представление исходного текста задано в ASCII-коде, каждый символ
текста переводится в 8-битный двоичный код. Полученная битовая строка
разбивается на блоки длиной 6 бит; в каждом блоке бит с позиции i
перемещается на позицию perm[i] согласно перестановке

    perm = [2, 6, 3, 5, 1, 4]

(бит 1 → на место 2, бит 2 → на место 6 и т.д.). Последний неполный блок
дополняется нулями, длина сообщения запоминается. При дешифровании
применяется обратная перестановка perm⁻¹ = [5, 1, 3, 6, 4, 2].

## Алгоритм работы программы
1. Ввод исходного текста; перевод каждого символа в 8-битный ASCII-код.
2. Склейка кодов в битовую строку; дополнение нулями до кратности 6.
3. Для каждого 6-битного блока выполняется перестановка perm.
4. Криптограмма выводится в двоичном и символьном виде.
5. Дешифрование: обратная перестановка, отсечение дополнения,
   перевод битов в текст; сравнение с исходным текстом.

## Текст программы (`lab1/lab1.py`)
```python
PERM = [2, 6, 3, 5, 1, 4]
L = len(PERM)

def text_to_bits(text):
    bits = []
    for ch in text:
        code = ord(ch)
        bits += [(code >> k) & 1 for k in range(7, -1, -1)]
    return bits

def permute(bits, perm):
    out = [0] * len(bits)
    for i, p in enumerate(perm):
        out[p - 1] = bits[i]          # бит i -> позиция perm[i]
    return out

def encrypt(text, perm=PERM):
    bits = text_to_bits(text)
    n_bits = len(bits)
    while len(bits) % L:
        bits.append(0)
    cipher = []
    for i in range(0, len(bits), L):
        cipher += permute(bits[i:i + L], perm)
    return cipher, n_bits

def inverse(perm):
    inv = [0] * len(perm)
    for i, p in enumerate(perm):
        inv[p - 1] = i + 1
    return inv

def decrypt(cipher_bits, n_bits, perm=PERM):
    inv = inverse(perm)
    bits = []
    for i in range(0, len(cipher_bits), L):
        bits += permute(cipher_bits[i:i + L], inv)
    return bits_to_text(bits[:n_bits])
```

## Контрольные вопросы
**1. Почему метод подстановки имеет слабую надёжность?**
Подстановка сохраняет частоты появления символов: частотный анализ
криптограммы позволяет сопоставить её символы с буквами языка по
известной статистике и восстановить текст без ключа.

**2. Что такое частотный анализ?**
Метод криптоанализа, основанный на подсчёте частот появления символов
(пар, троек) в шифртексте и сопоставлении их с известной статистикой
частот букв языка открытого текста.

**3. Что является криптографическим ключом в методе перестановки?**
Группа перестановок (правило перемещения элементов внутри блока) и длина
блока перестановки.

**4. Как связаны метод подстановки и многоалфавитные шифры?**
Многоалфавитный шифр — это набор из нескольких подстановочных алфавитов:
каждая позиция текста шифруется своей подстановкой, алфавиты применяются
циклически (например, шифр Виженера). Это разрушает прямую связь частот
символов открытого и зашифрованного текстов.

# Лабораторная работа № 2. Шифрование генератором ПСЧ (гаммирование)

## Цель работы

* количество разрядов **b = 7**, значит модуль **M = 2⁷ = 128**.

## Описание метода
Линейный конгруэнтный генератор строит последовательность

    T(i) = (A·T(i−1) + C) mod M

По теореме Кнута период последовательности максимален (равен M), если:
* C — нечётное (взаимно просто с M);
* A mod 4 = 1 (при M, кратном 4);
* 0 ≤ T(0) < M — начальное значение.

Выбраны параметры: **A = 29** (29 mod 4 = 1), **C = 77** (нечётное),
**T(0) = 11**.

Гаммирование: каждый символ исходного текста представляется b-битным
кодом, на него накладывается гамма — число ПСЧ T(i): `C_i = M_i ⊕ T(i)`.
Дешифрование — повторное наложение той же гаммы (XOR обратим).

## Алгоритм работы программы
1. Ввод текста (коды символов < 128).
2. Генерация гаммы длиной в сообщение по конгруэнтной формуле.
3. Побитовое XOR кодов символов с числами гаммы → криптограмма.
4. Дешифрование той же гаммой, сравнение с исходным текстом.
5. Пункт 4 задания: повторное шифрование с изменёнными параметрами
   генератора (A = 25, C = 51, T(0) = 3) и сравнение криптограмм.

## Текст программы (`lab2/lab2.py`)

# Лабораторная работа № 3. Сети Фейстеля

## Цель работы
Изучить принципы работы сети Фейстеля, научиться шифровать информацию
посредством блочного криптоалгоритма.

## Задание (вариант 11)
* количество раундов **n = 28**;
* образующая функция — **умножение по модулю 2ᴺ** (N = 32 бита — размер
  ветви).

## Описание метода
Используется модифицированная сеть Фейстеля: 128-битный блок делится на
четыре равные ветви X1 X2 X3 X4 по 32 бита; ключ K — 64 бита, разбитый на
половины K1 и K2. Параметр сети в раунде i:

    V_i(K) = (K1 ROL i) ⊕ (K2 ROR i)

Образующая функция варианта 11:

    F_i = (X1(i−1) · V_i(K)) mod 2³²

Итерация шифрования («+» — побитовое сложение по модулю 2, XOR):

    X1(i) = X2(i−1) ⊕ F_i
    X2(i) = X3(i−1)
    X3(i) = X4(i−1)
    X4(i) = X1(i−1)

Дешифрование производится той же сетью с инверсным порядком параметров —
раунды «раскручиваются» в обратном направлении (i = 28…1):

    X1(i−1) = X4(i)
    X2(i−1) = X1(i) ⊕ F_i   (F_i пересчитывается от X1(i−1)=X4(i))
    X3(i−1) = X2(i)
    X4(i−1) = X3(i)

Для этого не требуется вычислять обратную функцию F⁻¹ — ключевое свойство
сети Фейстеля.

## Алгоритм работы программы
1. Текст переводится в байты, дополняется нулями до кратности 16 байт
   и разбивается на 128-битные блоки (четыре слова по 32 бита).
2. Каждый блок шифруется 28 раундами сети Фейстеля.
3. Дешифрование — обратной итерацией тех же раундов; результат сравнивается
   с исходным текстом.

## Текст программы (`lab3/lab3.py`)
```python
MASK32 = 0xFFFFFFFF
N_ROUNDS = 28

def rol(x, i, w=32):
    i %= w
    return ((x << i) | (x >> (w - i))) & MASK32

def ror(x, i, w=32):
    i %= w
    return ((x >> i) | (x << (w - i))) & MASK32

def net_param(i, k1, k2):
    return rol(k1, i) ^ ror(k2, i)          # V_i(K)

def round_f(x1, v):
    return (x1 * v) & MASK32                # умножение mod 2^32

def encrypt_block(block, key):
    x1, x2, x3, x4 = block
    k1, k2 = (key >> 32) & MASK32, key & MASK32
    for i in range(1, N_ROUNDS + 1):
        f = round_f(x1, net_param(i, k1, k2))
        x1, x2, x3, x4 = x2 ^ f, x3, x4, x1
    return x1, x2, x3, x4

def decrypt_block(block, key):
    x1, x2, x3, x4 = block
    k1, k2 = (key >> 32) & MASK32, key & MASK32
    for i in range(N_ROUNDS, 0, -1):
        f = round_f(x4, net_param(i, k1, k2))
        x1, x2, x3, x4 = x4, x1 ^ f, x2, x3
    return x1, x2, x3, x4
```

## Анализ и выводы
Дешифрование полностью восстановило текст — сеть корректна и обратима

## Контрольные вопросы
**1. Какова структура классической сети Фейстеля?**
Входной блок делится на две равные ветви (подблоки) L и R; каждый раунд
вычисляется образующая функция F от одной ветви и параметра сети,
результат накладывается (XOR) на вторую ветвь, ветви меняются местами;
после последнего раунда выполняется размен ветвей.

**2. Что называется раундом в сети Фейстеля?**
Раунд (цикл) — однократное вычисление образующей функции и наложение её
результата на другую ветвь с обменом ветвей местами. Оптимальное число
раундов — от 8 до 32.

**3. Какими свойствами обладает сеть Фейстеля?**
Обратимость при любой (даже необратимой) образующей функции — обратное
преобразование не требует F⁻¹; симметричность — дешифрование выполняется
той же сетью с инверсным порядком параметров; неважна чётность числа
раундов.

**4. Каким образом используется материал ключа при шифровании?**
Ключ входит в параметры сети V_i(K) — функции от материала ключа
(в данной работе V_i = K1 ROL i ⊕ K2 ROR i). В явном виде ключ не
используется, что повышает криптостойкость.

# Лабораторная работа № 4. Изучение алгоритма RSA

## Цель работы
Освоить механизм шифрования и дешифрования данных в криптосистеме
с открытыми ключами RSA.

## Задание
1. Программа шифрования/дешифрования RSA.
2. Сообщение M — не менее 2n = 22 символов (n = 11).
3. Криптограмма сохраняется отдельным файлом.
4. В программе — проверка взаимной простоты двух чисел.

## Описание метода
1. Выбираются два больших простых числа p и q.
2. Вычисляются n = p·q и функция Эйлера φ(n) = (p−1)(q−1).
3. Выбирается e, взаимно простое с φ(n) — открытый ключ (e, n).
4. Находится d: (e·d) mod φ(n) = 1 — секретный ключ (d, n).
5. Шифрование: C(i) = M(i)ᵉ mod n; дешифрование: M(i) = C(i)ᵈ mod n.

Стойкость RSA основана на трудности факторизации n: зная только (e, n),
вычислить d нельзя, не разложив n на множители.

## Алгоритм работы программы
1. Генерация простых p, q (тест Миллера–Рабина), вычисление n и φ(n).
2. Выбор случайного e с проверкой gcd(e, φ(n)) = 1; вычисление d
   расширенным алгоритмом Евклида.
3. Демонстрация проверки взаимной простоты двух введённых чисел.
4. Побайтовое шифрование сообщения (код символа → mᵉ mod n),
   запись криптограммы в файл `cipher.txt`.
5. Чтение криптограммы из файла, дешифрование, сравнение с исходным
   текстом.

## Текст программы (`lab4/lab4.py`)

def is_prime(n, rounds=16):          # тест Миллера-Рабина

def egcd(a, b):                      # расширенный алгоритм Евклида
    if b == 0:
        return a, 1, 0
    g, x, y = egcd(b, a % b)

def mod_inverse(e, phi):
    g, x, _ = egcd(e, phi)

# шифрование:  C(i) = M(i)^e mod n

Однонаправленность для всех, кто не знает секрета; при наличии секретной

**4. Как реализуется программное возведение в степень для больших чисел?**
Алгоритмом быстрого (бинарного) возведения в степень: показатель
разбивается на степени двойки, выполняются возведения в квадрат и

чисел используется длинная (многократная точность) арифметика.

# Лабораторная работа № 5. ЭЦП по ГОСТ Р34.10-94

## Цель работы
Разработка процедур выработки и проверки электронной цифровой подписи
сообщений на базе асимметричного криптоалгоритма с функцией хэширования.

## Задание (вариант 11)
Алгоритм вычисления контрольной суммы (хэш-функции): **умножение кодов
символов исходного текста по модулю 2¹⁶**.

## Описание метода
Параметры системы ЭЦП (общие, не секретные):
* p — простое число (по ГОСТ 2⁵⁰⁹ < p < 2⁵¹²);
* q — простое число, простой делитель числа p−1 (по ГОСТ 2²⁵⁴ < q < 2²⁵⁶);
* a — целое, 1 < a < p−1, при этом a^q mod p = 1;
* x — секретный ключ (1 < x < q);
* y = aˣ mod p — открытый ключ;
* k — секретный сеансовый ключ, 1 < k < q, уничтожается после подписи.

В работе использованы учебные значения: p = 2039, q = 1019 (2039 = 2·1019+1,
оба простые), a = 100 = 10² mod 2039 (порядок делит q), x = 313, k = 77.

**Формирование подписи:**
1. h = H(m); если h mod p = 0, то h := 1.
2. Случайный k из [1, q).
3. r = (aᵏ mod p) mod q; если r = 0 — новое k.
4. s = (x·r + k·h) mod q; если s = 0 — новое k.
5. Подпись — пара чисел (r, s).

**Проверка подписи:**
1. Условия 0 < r < q, 0 < s < q.
2. h = H(m₁); если h mod p = 0, то h := 1.
3. v = h^(q−2) mod q.
4. z₁ = s·v mod q;  z₂ = (q−r)·v mod q.
5. u = ((a^z₁ · y^z₂) mod p) mod q.
6. Подпись верна, если u = r.

## Алгоритм работы программы
1. Вычисление открытого ключа y = aˣ mod p, контроль a^q ≡ 1 (mod p).
2. Хэш сообщения — произведение кодов символов mod 2¹⁶.
3. Формирование подписи (r, s), её проверка.
4. Изменение подписи (s' = s+1) и проверка — подпись должна отвергаться;
   то же для изменённого текста.

## Текст программы (`lab5/lab5.py`)
```python
P, Q, A = 2039, 1019, 100
X = 313                     # секретный ключ
K = 77                      # сеансовый ключ

def hash_msg(text):          # произведение кодов символов mod 2^16
    h = 1
    for ch in text:
        h = (h * ord(ch)) % 65536
    return h

def sign(text, x, k):
    h = hash_msg(text) % P
    if h == 0: h = 1
    while True:
        r = pow(A, k, P) % Q
        if r == 0:
            k = random.randrange(1, Q); continue
        s = (x * r + k * h) % Q
        if s == 0:
            k = random.randrange(1, Q); continue
        return r, s, h

def verify(text, r, s, y):
    if not (0 < r < Q and 0 < s < Q): return False
    h = hash_msg(text) % P
    if h == 0: h = 1
    v  = pow(h, Q - 2, Q)
    z1 = (s * v) % Q
    z2 = ((Q - r) * v) % Q
    u  = ((pow(A, z1, P) * pow(y, z2, P)) % P) % Q
    return u == r
```

## Анализ и выводы
Подпись (r, s) формируется только обладателем секретного ключа x и
проверяется открытым ключом y у любого получателя. Искажённая подпись и
изменённый текст отвергаются — ЭЦП обеспечивает аутентификацию,
целостность и невозможность отказа от авторства.

Отдельно стоит отметить слабость учебной хэш-функции: произведение кодов
mod 2¹⁶ обнуляется для длинных текстов с чётными кодами символов
(накапливается ≥16 двоек); тогда по стандарту h := 1 и разные тексты
получают одинаковую подпись. Реальные криптографические хэш-функции
(MD5, SHA, ГОСТ Р34.11) лишены этого недостатка.

## Контрольные вопросы
**1. Какие криптоалгоритмы используются для создания ЭЦП?**
ГОСТ Р34.10-94/2001/2012, RSA, DSA, ECDSA, Эль-Гамаль — алгоритмы
на задачах дискретного логарифмирования и факторизации.

**2. Что такое хэш-функция?**
Однонаправленная функция h = H(m), преобразующая данные произвольной
длины в строку фиксированной длины: по m легко вычислить h; по h трудно
подобрать m; трудно найти два сообщения с одинаковым хэшем.

**3. Что такое имитовставка?**
Контрольная комбинация (код аутентификации), вырабатываемая из сообщения
с использованием секретного ключа и присоединяемая к сообщению для защиты
от навязывания ложных данных — обеспечивает целостность и подлинность.

**4. Где используется ЭЦП?**
В электронном документообороте и юридически значимых документах, в
банковских и платёжных системах, при подписании программного обеспечения
и кода, в государственных информационных системах, электронной почте.

# Лабораторная работа № 6. Парольная защита (выборка символов)

## Цель работы
Получение навыков построения систем парольной защиты и ограничения
доступа несанкционированных пользователей к информации.

## Задание (вариант 11)
Вид парольной защиты — **выборка символов**: пользователь никогда не
вводит пароль целиком. При каждой попытке входа система по датчику
случайных чисел выбирает несколько позиций пароля и запрашивает только
символы на этих позициях.

## Описание метода
Пароль хранится в файле `passwd.dat` вместе с меткой времени последнего
удачного входа. При аутентификации:
1. Генератор случайных чисел выбирает набор различных позиций пароля
   (около половины длины), набор меняется при каждой попытке.
2. Система просит ввести символы на выбранных позициях; ввод
   производится без эха (символы маскируются `*` — msvcrt.getwch).
3. Все введённые символы сравниваются с соответствующими позициями
   пароля.
4. Даётся не более 3 попыток, после чего доступ блокируется.
5. При успехе выводится/обновляется время последнего входа.

Метод устойчив к подсматриванию и перехвату ввода: злоумышленник узнаёт
лишь часть символов и не знает, какие позиции будут запрошены в следующий
раз.
